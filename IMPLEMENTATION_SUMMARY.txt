IMPLEMENTATION SCRIPTS
================================================================================

Created three Python scripts:

1. add_skip_links.py
   - Adds skip-to-content links to all HTML files
   - Avoids duplicates
   - Handles various body tag formats
   - Adds CSS to style blocks

2. add_breadcrumbs.py  
   - Adds BreadcrumbList JSON-LD to non-top-level pages
   - Language detection from file path
   - Breadcrumb label lookup with language mappings
   - Page title extraction from <title> tags
   - Builds hierarchical breadcrumb paths

   - Cleanup script to remove schemas for re-running
   - Used during development to fix language detection bug
